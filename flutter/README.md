# saleba_design (Flutter)

Paquet Flutter du design system Saleba. Documentation, installation et règles : voir le
[README du dépôt](../README.md) et la [charte](../docs/CHARTE_GRAPHIQUE.md).

Régénérer les tokens après une modification de `../tokens/tokens.json` :

```sh
dart run tool/gen_tokens.dart
```
